I think that AI is only going to get more human-like, but I don't think it will ever truly gain consciousness or sentience in the way that the movies always depict. I think that it will look very much like it has, but that's it. I find the idea of holding computer logic accountable a bit odd, since computer logic only does what it was told to do. I think that people should be held accountable for whatever computer logic they write, but they can put safeguards into their code so that it doesn't do anything unexpected. For example, when Tony Stark and Bruce Banner made Ultron, they should have put in his code explicitly not to murder all of humanity (or anyone, really), since Ultron was technically doing as his code said and getting rid of the source of war on Earth. Tony Stark and Bruce Banner definitely should have been held accountable for that, though. I suppose you could also do a machine learning type of thing where you can train the computer to not do horrible things, but I think it would be better to just program it like that from the beginning.
